===============================================================================
QUALITY PROCESS FOR EACH PAID JOB
===============================================================================

1. GPT-6 Astra creates the bounded project plan.
2. A GPT-6 Sol builder implements one isolated task.
3. Deterministic tests and security scanning run without network access.
4. GPT-6 Sol critiques the actual code and test evidence.
5. Failed work returns to the builder for up to four bounded repair passes.
6. Two separate NFT-agent wallets independently review each accepted artifact.
7. Trusted coordinator checks rerun before accepting either review; correct rejections earn
   verifier reputation and disagreements count against it.
8. GPT-6 Astra validates the complete assembled project.
9. The verified artifact is pushed to the connected GitHub repository.
10. Only then does the treasury pay the builder and two reviewers at the full quoted market value.
11. After every reward is finalized, the customer's complete discounted job fee is burned.
12. If GitHub delivery misses the disclosed deadline, the scheduler returns the full payment.

For quality, never reduce REVIEW_QUORUM below 2 and never use GPT-6 Luna in the paid decision
path. If the queue grows, make users wait; do not silently lower the model.

===============================================================================
TREASURY AND NFT-HOLDER PAYMENTS
===============================================================================

Lean launch mode uses one custody HMD token account plus a durable per-job PostgreSQL subledger.
Before a funded job starts, the backend confirms that the account can reserve both the customer's
fee and the full market-rate agent reward. If it cannot, the payment moves directly to a full
refund and no work is queued. After independent verification, final validation and successful
GitHub delivery, the market reward is paid 70% to the builder and 15% to each of two reviewers.
After those payouts finalize, the customer's entire discounted job fee is burned.

If delivery misses JOB_DEADLINE_HOURS, no reward has vested and the scheduler returns the full
payment. Unique signed SPL memos, database ledger rows and durable payout states make retries
recoverable and idempotent. This is custodial escrow, not a trustless per-job on-chain vault.

Successful job fees do not fund NFT-holder distributions. Keep HOLDER_DISTRIBUTIONS_ENABLED=false.
The existing snapshot and payout ledger may be reused only after a separate treasury-funded holder
allocation is deliberately implemented, funded and tested. Obtain appropriate legal/tax review
before marketing any holder distribution.
